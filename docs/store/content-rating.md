# Content rating questionnaire (IARC): proposed answers

For Play Console > **Policy > App content > Content rating**. The questionnaire's exact wording
changes; answer what it asks, using the facts below. Wrong answers can get the rating overridden
or the app removed, so re-do it when the game changes (chat, real-money features, new themes).
Research: `docs/research/launch.md` §8.

## Category

- **Category**: Game (questionnaire category "Game" / "All other app types" is wrong: it's a game).
- **Play Store category** (Store settings): **Casual** (alternatives: Simulation, Sports). Tags to
  pick (up to 5): Fishing, Casual, Collecting, Arcade, Multiplayer (whichever Play offers).

## Answers

| Topic | Answer | Facts behind it |
| --- | --- | --- |
| Violence | **No** violence against humans or animals shown as harm. If asked about "fantasy/cartoon violence" or "harm to animals": **No**. | Fish are caught with a hook and become collection cards; no blood, injury, death or suffering is shown. Bumping a fish's head makes it dart away. |
| Fear / horror | **Mild** if the questionnaire distinguishes "content that may frighten young children"; otherwise **No**. | The deep gets darker, with spiny, toothy fish and glowing eyes; the optional **Nightmare** look (unlocked by reaching the Abyssal Floor, chosen by the player) is scarier. No jump scares, gore or horror themes. Answering "mild fear" is the honest choice for PEGI. |
| Sexuality, nudity | **No** | |
| Language | **No** profanity or crude humour | Player-typed battle names are free text shown to opponents and friends (see "Users interact"). |
| Controlled substances (drugs, alcohol, tobacco) | **No** | |
| Gambling: real money | **No** | Nothing can be won or cashed out. |
| Simulated gambling | **No** (read carefully, see note) | **Wagers**: before a battle against the computer, the player can stake game points (1k to 100k) and wins them back ×1.2 to ×2.4, or loses them. The outcome is decided by a skill battle the player fishes, not by chance, and points can't be cashed out or exchanged for money. Euros never buy points directly (the shop sells items; only the collector's edition's 10 skipped season tiers include the free track's small point rewards). There are no loot boxes, spins, gacha or random paid rewards. **Developer to confirm**: if the questionnaire's definition covers "betting virtual currency on an outcome", answer Yes (likely PEGI 12 / USK 12 instead of 3/0) or remove wagers before launch. |
| Digital purchases | **Yes**: in-app purchases (one-time items, consumable tackle packs, a season pass, a subscription). | Google Play Billing. No random items for money. |
| Users interact / share content | **Yes**: users can interact (online battles, friends, leaderboards). **No** chat, no messaging, no user-generated content beyond the battle name. | Players type a battle name shown to opponents and friends (never on public boards, which use a generated name); friends are added by player id; gifts can be sent to online opponents. |
| Shares location | **No** | No location permission; Analytics derives a coarse country from the IP only with consent. |
| Personal information shared with third parties | **No** (no personal info collected; see Data safety) | |
| Unrestricted internet / web browsing | **No** | The app only opens the privacy policy link. |
| Ads | **No** ads | |

## Expected result

PEGI 3 or 7 (7 if "mild fear" is declared), USK 0 or 6, ESRB Everyone, ClassInd L or 10, IARC 3+
or 7+, each with the interactive notices **In-Game Purchases** and **Users Interact**. If the
wager question is answered Yes, expect PEGI 12 / USK 12 / ESRB Teen-level gambling descriptors:
decide before submitting, because changing it later changes the store badge.
